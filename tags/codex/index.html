이전 글 Herdr 완벽 가이드: AI 코딩 에이전트를 위한 터미널 멀티플렉서에서 에이전트 인식형 터미널 런타임인 Herdr의 기본 개념과 CLI 명령어 구조를 살펴보았습니다. 하지만 개발자가 터미널에서 패널을 쪼개고, 에이전트 프로세스를 하나하나 띄우며 CLI 명령어를 직접 타이핑하는 것은 여전히 많은 수작업을 요구합니다. 우리가 궁극적으로 지향하는 작업 환경은 **“오케스트레이터 에이전트에게 사람에게 말하듯 목표를 던지면, 오케스트레이터가 하위 작업자 에이전트들을 적재적소에 배치하고 협업을 지휘하는 구조”**입니다. 이 글에서는 Hermes Agent를 총괄 오케스트레이터로 두고, 실제 코딩과 테스트를 수행하는 작업자로 **Claude Code(claude)**와 **Codex(codex)**를 배치하여 Herdr 환경에서 자연어로 멀티 에이전트를 지휘하는 실전 시나리오 5가지를 정리합니다. 복잡한 CLI 절차를 나열하지 않고 사람에게 일을 맡기듯 지시하는 자연어 프롬프트와, 그 이면에서 Hermes가 Herdr를 제어하는 내부 동작 방식을 함께 살펴봅니다. ...
