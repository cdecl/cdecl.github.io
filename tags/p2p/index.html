Tailcat 완벽 가이드: 제어 플레인 없는 P2P WireGuard 터널링과 차세대 netcat의 도래

네트워크 엔지니어와 DevOps 엔지니어들에게 netcat(nc)은 지난 수십 년간 “네트워크의 스위스 아미 나이프"로 불려왔습니다. 두 호스트 간에 표준 입출력(stdin/stdout)을 파이프로 연결하고, 임의의 TCP/UDP 포트를 열고 닫으며, 방화벽 상태를 진단하고 임시 데이터 파이프라인을 구축하는 데 netcat만큼 직관적이고 강력한 도구는 없었습니다. 하지만 현대의 클라우드, 컨테이너, 홈랩 환경은 1990년대의 평면적인 네트워크와 전혀 다릅니다. 대부분의 인프라는 NAT(Network Address Translation) 뒤편에 격리되어 있고, 엄격한 방화벽과 사설 서브넷으로 둘러싸여 있으며, 평문 TCP 통신은 보안상 절대 허용될 수 없습니다. ...
