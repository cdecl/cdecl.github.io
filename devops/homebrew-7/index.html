Homebrew 7.0.0이 2026년 9월 13일 출시됐습니다. 더 빠른 설치, 강력한 샌드박싱, 네이티브 macOS 앱, 취약점 검사 기능 등 대규모 개선이 이루어진 메이저 업데이트입니다.

원문: https://brew.sh/2026/09/13/homebrew-7.0.0/

Homebrew란?#

  • https://brew.sh/
  • macOS와 Linux에서 소프트웨어를 쉽게 설치하고 관리할 수 있는 오픈소스 패키지 관리자
  • Ruby로 작성되어 있으며, GitHub에서 활발하게 개발 중
  • CLI 도구(Formulae)와 GUI 앱(Cask) 두 가지 방식으로 패키지 관리

설치#

macOS#

# Homebrew 설치
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"

# 설치 확인
brew --version

Linux (Ubuntu/Debian)#

# Homebrew 설치
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"

# PATH 설정 (zsh/bash)
eval "$(/home/linuxbrew/.linuxbrew/bin/brew shellenv)"

# 설치 확인
brew --version

Apple Silicon (M1/M2/M3/M4) macOS#

# Apple Silicon 기본 경로: /opt/homebrew
eval "$(/opt/homebrew/bin/brew shellenv)"

주요 명령어 Cheatsheet#

📦 패키지 관리 (Formulae)#

# 패키지 검색
brew search <package>
brew search wget

# 패키지 설치
brew install <package>
brew install wget

# 패키지 정보 확인
brew info <package>

# 설치된 패키지 목록
brew list
brew list --formula    # Formula만
brew list --cask       # Cask만

# 패키지 업그레이드
brew upgrade           # 전체 업그레이드
brew upgrade <package> # 특정 패키지 업그레이드

# 패키지 제거
brew uninstall <package>

# 패키지 의존성 확인
brew deps <package>
brew deps --tree <package>

🖥️ GUI 앱 관리 (Cask)#

# Cask 패키지 설치
brew install --cask <package>
brew install --cask google-chrome

# Cask 패키지 업그레이드
brew upgrade --cask
brew upgrade --cask <package>

# Cask 패키지 제거
brew uninstall --cask <package>

🔄 업데이트 및 유지보수#

# Homebrew 자체 업데이트
brew update

# 오래된 패키지 확인
brew outdated

# 캐시 및 이전 버전 정리
brew cleanup
brew cleanup --dry-run  # 삭제될 목록 미리 확인
brew cleanup -s         # 캐시도 함께 정리

# 시스템 진단
brew doctor
brew missing

🔍 정보 조회#

# Homebrew 환경 정보
brew config

# 탭(Tap) 목록
brew tap
brew tap-info --installed --json=v1

# 패키지 홈페이지 열기
brew home <package>

# 패키지 파일 경로 확인
brew --prefix <package>
brew --cellar <package>

📋 Brewfile (번들 관리)#

# 현재 설치된 패키지를 Brewfile로 저장
brew bundle dump

# Brewfile에서 패키지 일괄 설치
brew bundle install
brew bundle install --file=./Brewfile

# Brewfile 체크
brew bundle check

# Brewfile에 없는 패키지 정리
brew bundle cleanup

Homebrew 7.0.0 신규 기능 및 특징#

🏎️ 성능 개선#

7.0.0의 가장 큰 변화 중 하나는 병렬 처리 강화입니다.

  • 동시 다운로드/설치: brew install, brew reinstall, brew upgrade 실행 시 패키지 준비와 다운로드가 겹쳐서 실행됨 — Brewfile 배치 처리도 동일하게 적용
  • brew config 병렬화: 컴파일러, OS, 저장소 정보를 동시에 수집하여 진단 속도 향상
  • brew tap-info 병렬화: 여러 탭에 대한 메타데이터 수집을 동시에 처리
  • brew cleanup 최적화: 반복적인 캐시 스캔 제거로 다수 패키지 정리 속도 향상
  • brew fetch 개선: API 메타데이터에서 직접 다운로드 정보를 읽어 패키지 정의 로딩 없이 즉시 다운로드 시작
  • brew update 후 Ruby 캐시 준비: 이후 명령어 실행 속도 개선
  • API 데이터 재사용: 워밍업된 실행에서 서명 검증을 유지하면서 파싱된 데이터를 재사용
  • 시작 시 서브프로세스 감소: 명령어 오버헤드 감소, 터미널 크기를 직접 읽어 stty 관련 행업 방지

🔒 보안 강화#

보안 취약점 데이터베이스 (Security Advisories)#

  • 내장 취약점 검사: brew audit --new 실행 시 Homebrew 고유 취약점 데이터베이스(Advisory DB)를 활용한 CVE 검사
  • brew audit --severity: 심각도 기반 필터링 지원
  • brew advisory: 패키지의 알려진 취약점 목록 조회
# 취약점 검사
brew audit --new <package>
brew audit --severity critical

# 특정 패키지 취약점 조회
brew advisory <package>

설치 및 탭 보호 강화 (Sandboxing)#

  • 강화된 샌드박싱: 설치 시 더 엄격한 파일시스템 접근 제한 적용
  • Setuid 래퍼 거부: 실제 UID와 유효 UID가 다른 setuid 래퍼는 거부됨 — 설치 소유자로 직접 실행 필요
  • 서드파티 brew 래퍼: Tier 3로 전환, 내부 명령어는 래퍼를 우회하므로 래퍼 프로젝트에서 지원을 받아야 함

🖥️ 네이티브 macOS 앱 (Homebrew App)#

7.0.0의 가장 눈에 띄는 신기능으로, Homebrew 네이티브 macOS 앱이 출시됐습니다.

  • 메뉴바에서 Homebrew 상태 모니터링
  • GUI를 통한 업데이트/업그레이드 실행
  • 알림을 통한 패키지 업데이트 안내
  • .pkg 파일로 설치 가능 (macOS Sequoia 15+ 지원)

🔎 명령어 및 설정 개선#

  • 다양한 brew 명령어의 옵션 추가 및 개선
  • post_install 및 cask flight 블록 → *_steps 형식으로 마이그레이션 (2027-12-11 제거 예정)
brew style --fix  # 자동 변환

🗃️ Cask 개선#

  • Cask 설치 과정에 더 세분화된 *_steps 인터페이스 도입
  • macOS Sequoia 15+ 에서 .pkg 설치 방식 개선

업그레이드 방법#

자동 업그레이드#

Homebrew는 기본적으로 자동 업데이트됩니다. brew install, brew upgrade 등의 명령어 실행 시 자동으로 최신 버전으로 업데이트됩니다.

수동 업그레이드#

# Homebrew 업데이트 (자동 업데이트를 비활성화한 경우)
brew update

# 버전 확인
brew --version

Breaking Changes 대응#

# CI에서 사용하는 경우 Docker 이미지 변경 필요
# 기존: ghcr.io/homebrew/ubuntu22.04 (제거됨)
# 변경: ghcr.io/homebrew/brew

# GitHub Actions에서 Homebrew/actions 사용 시
# 기존: Homebrew/actions/*@master 또는 @main (master 브랜치 제거됨)
# 변경: CalVer 릴리스 또는 full SHA로 고정
# 예: Homebrew/actions/setup-homebrew@2025.1.0

마이그레이션 타임라인#

항목조치기한
ghcr.io/homebrew/ubuntu22.04ghcr.io/homebrew/brew로 마이그레이션즉시 (7.0.0)
Homebrew/actions/*@masterCalVer 릴리스 또는 SHA로 고정즉시 (7.0.0)

Homebrew/brew master 브랜치main 브랜치로 전환2027-03-01

결론#

Homebrew 7.0.0은 단순한 버전 업그레이드가 아닌 성능, 보안, 사용성 전반에 걸친 대규모 개선입니다.

  • 빠른 설치: 병렬 처리 강화로 체감 속도 향상
  • 보안 강화: 내장 취약점 데이터베이스와 강력한 샌드박싱
  • 네이티브 앱: macOS 사용자를 위한 GUI 인터페이스 제공
  • Intel Mac 지원 종료 예고: 2027년 9월부터 Intel Mac은 Tier 3로 전환

Intel Mac 사용자는 MacPorts로의 마이그레이션을 미리 검토하고, CI/CD 파이프라인에서 Homebrew를 사용하는 경우 Docker 이미지와 GitHub Actions 참조를 즉시 업데이트해야 합니다.
